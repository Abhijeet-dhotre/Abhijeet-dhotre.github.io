QuickPrompt AI

Make any text a better prompt — without leaving the app you're in.

A Windows system-wide prompt enhancer and voice dictation tray app. Select text anywhere, enhance it in place, or dictate straight into the app you were typing in — no copy-paste round trips, packaged as a single QuickPromptAI.exe.

How it works: select text in any app and press Ctrl+Shift+E to enhance it in place, or Ctrl+Shift+Q to dictate straight into the app you were typing in. The repo is the way to try it — download and run the tray app.

  • Three modes — Quick Fix, Prompt Enhance and Advanced Optimize
  • Five providers — OpenAI, Claude, Gemini, Groq and any OpenAI-compatible endpoint
  • Keys stay private — stored only in Windows Credential Manager

Shortcuts (per README)

Ctrl + Shift + E
Enhance selected text

Ctrl + Shift + Q
Voice dictation

Works system-wide, in whatever app is focused.

SafeToy — AI Chat Robot for Children

A talking robot a child can actually hold.

A child-friendly voice robot built on the ESP32-S3. The child presses to talk; the robot listens, thinks and answers out loud — with a face that shows how it feels.

  • Push-to-talk interaction, not always-listening
  • Whisper speech recognition → Llama responses
  • Emotion detection with OLED eyes that display emotions
  • Edge TTS for spoken replies

CodeShareX

Share a doc or a file with just a 6-digit code.

Real-time collaborative document editing plus peer-to-peer file sharing. Join with a short session code — files travel directly between peers instead of sitting on a server.

How it works: start a session, share the 6-digit code, and everyone co-edits the document in real time. Files transfer peer-to-peer over WebRTC — nothing is stored on a server. Open the repo to run it.

  • Live collaborative editing over WebSockets
  • P2P file transfer over WebRTC
  • 6-digit session codes to join a room
  • No server storage for transfers

RVC Colab Notebook

Voice conversion in the cloud — no local install.

A Google Colab notebook that converts any voice with a trained Retrieval-Based Voice Conversion (RVC) model, entirely in the cloud. Files live in Google Drive; you hear the result right in the notebook.

  • Runs entirely in Google Colab with CUDA acceleration
  • Google Drive for model & file storage
  • rmvpe pitch extraction, with inline audio preview

SVM on CIFAR-10

Classical ML, done properly — ~61% without a neural net.

Image classification on CIFAR-10 using hand-crafted features and a Support Vector Machine instead of deep learning — a study in how far classical methods can go.
